What exactly is running?

The page downloads a Python interpreter that runs inside your browser (a project called Pyodide), then the model's own code, settings and input data, unchanged. When you press the button it calls the very same function the researchers call from their command line. The only difference is the versions of the number-crunching libraries, so every run is fingerprinted and compared with the researchers' stored run of the same settings. “Same as the researchers' run” means every person's choice, departure time and gate-crossing minute matched exactly.

If you'd rather run it on your own computer, the whole thing is on GitHub:

cd cordon_lite
python -m cordonlite.run --arm R-clock --seed 1 --peak-fee 6
python -m cordonlite.run --arm R-daily --seed 2 --peak-fee 18 --traits off --set events.pt_disruption_day=[3,8]
