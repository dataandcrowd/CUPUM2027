Under the hood

For the curious: formulas, parameters and files

This page is for readers who want to run or change the model. The code name of the model in the repository is Cordon-Lite. The full account, with its history and every design decision, is in cordon_lite/README.md, INTERFACES.md and DEVIATIONS.md on GitHub.

Command line

python3.12 -m venv .venv && .venv/bin/pip install -r requirements.txt
python -m cordonlite.run --arm R-clock --seed 1                # a run: runs/R-clock_mock_py_s1
python -m cordonlite.run --arm R-daily --peak-fee 18             # another charge: _peak18
python -m cordonlite.run --arm R-clock --set events.pt_disruption_day=[3,8] --name R-clock_mock_py_s1_pt3_pt8
python -m cordonlite.run calibrate --seeds 1 2 3                 # gate capacity -> data/calibration.json
ANTHROPIC_API_KEY=... python -m cordonlite.run --arm H-clock --backend anthropic --seed 1
python scripts/chapter_figures.py                                # runs/figures/chapter/
python scripts/build_docs_site.py                                # the data behind this website
python -m pytest

Run folders are named <arm>_<backend>_<engine>_s<seed> plus a suffix for every setting that differs from config.toml. Outputs are byte-identical for identical inputs with the rule and either engine.

Generalised cost

With a = VoT/60 (NZ$ per minute), k = kappa_H (halved at a discontinuity wake), phi, omega and eta the disposition multipliers, and the standing option the routine:

CAR at departure d
  R   = public road delay on the route when leaving at d (yesterday's traffic; usual traffic on morning 1)
  g   = d + free-flow minutes to the gate + floor(R + 0.5)          expected gate arrival
  D   = public queue delay at g (yesterday, 5-min bins) x personal delay ratio (EMA)
  x   = g + round(D)                                                 expected crossing minute
  arr = x + free-flow minutes from the gate to work
  time     = a x (free-flow total + R + D)
  schedule = phi x sched_mult x a x (0.61 x early + 2.38 x late)     against the cheaper of t* and the 07:00 start (+ NZ$3 x phi)
  fee      = f(x) + eta x max(0, f(x) - reference fee)               0 for a company car
  parking  = daily parking;  fuel = 2 x km x NZ$0.30
  habit    = k if d is not the standing departure
PT
  pt       = omega x (a x T_pt + PAP) + fare,  T_pt = 1.6 x free-flow car time + 10 (x2 when disrupted)
  schedule = phi x sched_mult x a x 0.61 x early                     latest 10-min service arriving by the start
  habit    = k unless PT is the routine
WFH
  wfh      = k_WFH x phi + a x free-flow total + parking + fuel      (no commute, parking or fuel credit)
  habit    = k unless WFH is the routine
Choice: argmin over options of GC - Gumbel(0, NZ$0.50)
Willingness to pay: WTP = -ln(u) x VoT / beta, beta = clip(0.15 x 9.97 / VoT, 0.1, 2); a car option with f(x) > WTP is not offered

What this website does, and does not, reproduce

  • Replay and results read the stored runs exported by scripts/build_docs_site.py: modes, departures, gate times, delays, charges and every logged reason. Positions along a route are interpolated by free-flow time between a car's departure and gate arrival, which is a drawing convenience: the engine computes only the total road delay, not where on the route it was lost.
  • Run it yourself runs the repository's Python in the browser, unmodified. Only the rule arms run there; the H-clock arm needs the Claude API. Each browser run is hashed and compared with the stored run of the same settings, and the match is reported.
  • The cost explorer re-implements the generalised cost of options.py in JavaScript. It is checked against the Python values for every commuter and option on morning 6 when the page loads, and the largest difference is reported next to the explorer.
  • The NetLogo twin, the level-of-service outputs and the calibration searches are not replicated here.
